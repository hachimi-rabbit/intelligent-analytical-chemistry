## 验证与适用边界

全量主案例：5,228条来源记录全部保留，10条标签冲突记录隔离；5,218条用于四个最终模型的训练。五折验证覆盖606类、3,419条谱、1,789个组。组级正确率为多数类1.06%、近邻70.04%、PCA8＋逻辑回归46.90%、SVM71.10%。单组类别不参与新标本评分，未做外部实验室测试。当前方法与限制见[第4章4.8.7节](../../../../../docs/ch04.md)。

以下为保留的三类入门案例历史记录：52条实测谱与22个ID，原始数值对、来源和CC BY 4.0归属均已保留。22折按ID隔离，四个固定候选全报。三个分类模型标本宏F1为1.0000，多数类为0.2083。石膏仅2个标本，尚无独立外部测试，不作真实跨仪器结论。真实实验在独立中文路径完整复现，8个结果文件与基准逐字节一致；278项数据、身份、指标与网页数值核验和5项完整性回归检查通过。离线页面检查覆盖208种谱图/模型组合及手机宽度。真实数据汇报含12页，表格与图表可在PPTX中编辑，PDF用于阅读预览。

以下为历史**模拟模块**的检查记录：

- 在新建Python 3.12环境中安装锁定依赖并复现，8个关键预测与结果文件和首次输出一致。
- `verify.py`的83项检查通过，涵盖指标复算、标本隔离、配对身份、种子完整性、校准分区互斥、候选覆盖和网页数据一致性。
- 离线交互检查覆盖32种CV组合、A/B仪器、15组结果矩阵、答案切换及桌面/手机宽度。
- 12页汇报稿已做结构检查与逐页渲染检查。

2026-10-25补充核验：在Linux/Python 3.12环境中，用 `reproduce.py` 在含中文路径的独立目录跑通全部5步，8个关键CSV/JSON文件与仓库基准逐字节一致；5项回归测试确认完整结果通过、陈旧网页数据及缺失/重复预测会被拒绝。Windows命令已给出，尚待组员在实际Windows电脑上复现。

这些是当前版本的技术检查记录，不能代替组员理解、独立复现、真人评审或实际课堂汇报。完整教材预览中另有原站搜索插件错误；此前对照确认修改前后均出现，独立互动模块可正常使用。测试不证明模拟条件代表真实矿物谱图。

种子2026属于已查看的历史教学基准。扩展实验报告五个固定种子与所有候选；其高分不等于真实跨仪器有效性。模拟模块未读取实测谱；新增真实模块另行下载DTU的历史RRUFF衍生存档，结果分开报告。199次标签置换的分位数不解释为正任务置信区间。

概率校准使用独立二分类模拟，与拉曼实验分开。拟合、校准、阈值验证、最终测试四部分互斥；结果如实报告Brier略变差，不强行得出校准改善的结论。
