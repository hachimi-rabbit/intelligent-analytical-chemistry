## 验证与适用边界

- 在新建Python 3.12环境中安装锁定依赖并复现，8个关键预测与结果文件和首次输出一致。
- `verify.py`的75项检查通过，涵盖指标复算、标本隔离、配对身份、种子完整性和校准分区互斥。
- 离线交互检查覆盖32种CV组合、A/B仪器、15组结果矩阵、答案切换及桌面/手机宽度。
- 12页汇报稿已做结构检查与逐页渲染检查。

这些是当前版本的技术检查记录，不能代替组员理解、独立复现、真人评审或实际课堂汇报。完整教材预览中另有原站搜索插件错误；此前对照确认修改前后均出现，独立互动模块可正常使用。测试不证明模拟条件代表真实矿物谱图。

种子2026属于已查看的历史教学基准。扩展实验报告五个固定种子与所有候选；其高分不等于真实跨仪器有效性。未读取RRUFF实际谱图，RRUFF只作为后续真实数据来源建议。199次标签置换的分位数不解释为正任务置信区间。

概率校准使用独立二分类模拟，与拉曼实验分开。拟合、校准、阈值验证、最终测试四部分互斥；结果如实报告Brier略变差，不强行得出校准改善的结论。
