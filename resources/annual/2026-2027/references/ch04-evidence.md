## 六对矿物关系的证据边界

| 历史来源标签 | 矿物学依据 | 本项目尚不能推出的结论 |
|---|---|---|
| Amblygonite / Montebrasite | [25]原文摘要及pp.1112–1113：F/OH系列，约600、1060、3375 cm⁻¹的信息；约600峰用于估计F含量的关系较弱 | 没有误判标本的F含量；未证明窗口截取导致特定误判 |
| Pyrope / Almandine；Grossular / Andradite | [26]端元/结构分类；[27]出版社摘要研究这些端元及部分固溶系列的拉曼振动 | 不代表全部峰相同或必然难分；没有本组端元比例的化学实测 |
| Richterite / Fluororichterite | [28]角闪石分类；[30]出版社摘要直接研究合成OH/F系列 | 红外峰行为不能直接替代拉曼峰分析；激光波长也不等于仪器身份 |
| Tremolite / Actinolite | [28]位点分类；[32]两条目确认钙质角闪石系列与Mg/Fe组成范围 | 名称不能直接给出每个标本的精确组成或其错误原因 |
| Fluoruvite / Dravite | [29]多位点分类；[31]CaMg₃(Al₅Mg)(Si₆O₁₈)(BO₃)₃(OH)₃F；[32]Dravite条目 | 两者差异涉及Ca/Na、Mg/Al与F/OH，不能说只是OH/F互换；没有用CSIRO反射谱代替拉曼数据 |
