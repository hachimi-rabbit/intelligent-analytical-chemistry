# 2026–2027 学年传承题库

这里的题目由本届学生为下一届学生设计。题目不追求偏、怪或重复计算，而应检验一个能够迁移到真实分析问题的判断。每道题应在本页相应章节下添加：题目标题、题型、考查目标、题干、答案要点、所需数据/代码链接和贡献 PR。

## 题目质量要求

- **有对象**：给出足以作答的样品、测量条件、矩阵/谱图/图像或数据背景。
- **有判断**：不能只要求复述定义；应要求比较方法、识别假设、解释失败或完成推导。
- **有答案边界**：写出关键得分点与常见误区，而不是只放最终数值。
- **可传承**：不依赖已失效的临时网页、私人数据或本届课堂口头信息。

### ch04

#### 题一 高分来自化学还是标本身份

题型：数据判断。目标：区分扫描行与独立标本，理解随机标签负对照。

题干：72个矿物标本各有3条A仪器谱。1NN逐谱随机宏F1为0.9861，按标本分组为0.5537。把标本标签随机置换并重复199次，两个策略的宏F1均值分别为0.9818与0.3335。解释这些结果。能否把两种正任务分数的差都称为泄漏的因果效应？

答案与评分点，10分：独立单位是72个标本而不是216条谱（2）；逐谱划分共享标本信息（2）；随机标签高分表明身份记忆可产生高分（2）；按组负对照围绕偶然水平波动，不必每次等于1/3（2）；两种划分也改变训练标本覆盖，分差不是纯因果量，负对照不否认正任务含化学信号（2）。

#### 题二 全量PCA与嵌套选择

题型：纠错与伪代码。目标：识别无监督预处理和模型选择泄漏。

题干：某组在全部540条谱上标准化并做PCA，再按标本分组交叉验证SVC，最后报告最优参数的CV分数。请指出至少两个问题并给出修正流程。

答案与评分点，10分：测试数据参与均值、尺度与载荷估计（3）；在同一CV中选参数并报告最优值有选择偏差（2）；先按标本/目标域保留外部集，预处理进入Pipeline，内外层均按组划分（3）；保留外层预测，冻结流程后只评估留出，不用留出选择预处理（2）。常见误区：“PCA没用标签，所以全量PCA没有泄漏”。

#### 题三 宏F1 平衡准确率与证据边界

题型：计算与论证。目标：正确计算指标并识别过度推广。

题干：18个留出标本每类6个，模型全部预测为石英。计算平衡准确率和宏F1。若某种处理流程在模拟B仪器上达到宏F1=1，能否称其解决了真实跨仪器迁移？

答案与评分点，10分：三类召回率为1、0、0，平衡准确率1/3（3）；石英precision=1/3、recall=1、F1=1/2，另两类F1=0，宏F1=1/6（3）；高分受模拟峰形、背景、类别范围和扰动设定限制，需真实配对谱、独立来源和仪器质量控制验证（4）。

#### 题四 阈值选择与校准边界

题型：流程设计。目标：让阈值选择不污染最终测试。

题干：将数据分成训练和测试后，在测试上搜索假阴性代价为8、假阳性代价为1的最低损失阈值，并把该损失作为最终性能。这有什么问题？校准后的Brier分数略增时应该怎么办？

答案与评分点，10分：测试标签参与选择造成乐观偏差（3）；区分模型拟合、概率校准、阈值选择与最终测试，或在开发集内部交叉拟合完成选择（3）；相关样品每一层都应按组隔离（2）；如实报告Brier略增，结合可靠性图与样本量分析，不为得到改善而挑测试集（2）。

#### 题5：52条谱是否等于52个独立样本？

题型：验证设计。考查目标：区分标本、扫描和仪器元数据。

题干：真实子集包含52条谱、22个RRUFF ID，波长包括514、532、780、785 nm。若随机按谱划分训练与测试，并把532/785 nm称为两台仪器，分别存在什么问题？本项目如何修正？

答案与评分点，10分：重复谱可能把同一标本放在两侧（3）；应按RRUFF ID整组留出并核对名单，主指标按标本汇总（3）；激光波长不能唯一标识仪器，也未证明同一标本的配对测量（2）；ID仍可能共享产地或母岩，更高层级依赖须另查（2）。数据与代码：`code/ch04_exercises/rruff_real/data/manifest.csv`、`outputs/folds.json`。

#### 题6：三类入门验证满分能说明什么？

题型：结果解释。考查目标：小样本、不平衡、外部有效性与后续选模。

题干：石英、方解石各10个标本，石膏2个。三个固定模型留一ID验证均22/22正确。能否宣布复杂模型最佳、现实识别率100%，或沿用旧模拟的跨仪器结论？写出下一步。

答案与评分点，10分：三个候选同分，不能证明复杂模型有额外收益（2）；石膏只有两个独立ID，结果不稳定且无外部验证（3）；数据库内验证不能支持真实跨仪器结论，来源处理与模拟arPLS效果需区分（2）；补充独立标本及目标仪器元数据，冻结流程，用新留出集或嵌套分组验证评估后续选择（3）。数据与代码：`code/ch04_exercises/rruff_real/outputs/metrics.json`、`README.md`。

#### 题7：5,228条来源谱为什么不等于5,228条验证谱？

题型：数据审查与验证设计。目标：区分来源记录、训练记录和折外评分对象。

题干：全量存档含5,228条谱，10条存在标签冲突。审查后有1,063个类别只有一个验证组。最终训练用5,218条，折外验证用3,419条。能否为使所有谱都有测试结果而把单标本的重复扫描随机拆开？为什么2,853个标本只有2,852个验证组？

答案与评分点，10分：冲突记录保留原因但不训练（2）；单组类没有同类独立新组，不能拆扫描冒充验证（3）；相同输入的跨标本记录保守合组以防泄漏（2）；最终全量拟合与折外评估用途不同，训练成绩不当测试成绩（3）。数据依据：`rruff_full/data/manifest.csv`、`outputs/spectrum_folds.csv`。

#### 题8：哪个模型更好？

题型：指标解释。目标：按评价目的解读模型结果。

题干：全量分组结果中，SVM正确率71.10%、宏F1为0.6711；近邻正确率70.04%、宏F1为0.6776。能否直接宣布SVM全面胜出？能否把它与三类入门案例的100%作单变量比较？

答案与评分点，10分：正确率与宏F1权重不同，结论取决于任务目标（3）；没有显著性检验，微小差异不直接证明稳定优势（2）；类别、输入区间、划分和样本规模同时改变，不能把差异仅归因于数据量（3）；单组类未获新标本评分，且没有外部实验室测试（2）。数据依据：`rruff_full/outputs/metrics.json`。
